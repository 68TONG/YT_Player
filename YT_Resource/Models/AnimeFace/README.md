# Anime face detector model

The bundled `model.onnx` is the `face_detect_v1.4_n` model from
[deepghs/anime_face_detection](https://huggingface.co/deepghs/anime_face_detection),
pinned to revision `784dc4c0bb692351ddcdbe6131a050b17d3025d5`.

The upstream model card declares the model under the MIT license and identifies
`deepghs/anime_face_detection` as its dataset. The upstream card reports an F1
score of 0.94 and a confidence threshold of 0.278 for this model.
